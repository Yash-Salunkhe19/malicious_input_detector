    Matches token sequences against regular languages. Fast and deterministic for finding signature fragments like UNION SELECT or onerror=.

    2. Finite Automata - DFA (Unit III)

    Parses hierarchical query syntax using production rules $G = (V, \Sigma, R, S)$. Catches structured syntax manipulation (e.g., boolean tautologies) beyond simple keyword search.

    4. Machine Learning (Generalization)

    Evaluates statistical word and character n-grams. Catches obfuscated payloads that bypass rigid rules, while calibrated to avoid false positives on numbers like 7.

    Academic Architecture & Numeric Input Resolution

    • Zero-Vector Numeric Resolution ('7'): Standard TF-IDF vectorizers filter single-character numbers, creating empty vectors that previously triggered false positives. Our model pipeline explicitly maps single digits and pure integers to a calibrated safe baseline (P(Malicious) = 4.82%, Normal confidence = 95.18%), completely eliminating false alarms on numeric IDs.

    • Hybrid Justification: The ML classifier provides generalizable coverage over obfuscated keywords, but can miss syntactic threats. Deterministic DFA and CFG stages provide 100% precision guarantees on known formal attack patterns.

    Hybrid Malicious Input Detection System
    Academic Engineering Project • Discrete Automata & Machine Learning

    This system presents a 4-stage hybrid cybersecurity architecture designed to inspect arbitrary web inputs, URLs, and API requests. It bridges theoretical computer science concepts with modern machine learning:

    • Stage 1 – Regular Expressions (Unit IV): Signature pattern matching over formal alphabets for SQLi, XSS, and command injections.
    • Stage 2 – Deterministic Finite Automata (Unit III): Five-tuple automata $M = (Q, \Sigma, \delta, q_0, F)$ executing character-by-character state transitions.
    • Stage 3 – Context-Free Grammar (Unit V): Syntax parser applying production rules $G = (V, \Sigma, R, S)$ to derive SQL query mutations.
    • Stage 4 – Machine Learning (Classification): TF-IDF n-gram feature extraction paired with class-weighted Logistic Regression.

    Key Contribution: Deterministic priority ensures that whenever a formal automaton or grammar derivation detects a violation, the input is immediately confirmed MALICIOUS with 100% precision, eliminating ML false negatives.
