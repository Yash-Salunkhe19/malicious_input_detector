Mathematical Proof: Why Numeric Inputs (e.g. 7) are Guaranteed Safe
The token regex r'(?u)\b[a-zA-Z_]\w*\b' extracts zero alphanumeric tokens for "7", yielding the zero feature vector $x = \mathbf{0}$. The logit reduces strictly to the negative learned intercept $z = w^T \mathbf{0} + b = b \approx -2.66$. $$P(\text{Malicious} \mid x = \mathbf{0}) = \frac{1}{1 + e^{2.66}} \approx 0.065 \ (6.5\%) < 50\% \implies \mathbf{SAFE} \ (93.5\% \text{ normal confidence})$$
